### [18:55] Rendered five round-2 concept stills for a sixth redesign direction   (branch: yls-redesign main · commits: none)

**Synopsis:** The owner asked for one more site design, different from the five built, intuitive and on brand, with five screenshot renders to choose from. Built five concept heroes as stills (not site pages yet) and sent them for selection. All five are light and product-led, because the five built designs are dark scroll scenes.

**What worked:** Evidence: `manual:` each PNG viewed after render at 1600×1000 (`tools/concepts/out/concept-1..5-*.png`); the render log printed `done` for c1, c2, c4, c5; c3 has no 3D.
- Concept 1 The Pad: the page is a legal pad, index tabs are the nav. Concept 2 The Sorting Case: a wooden sorting case, one slot per section. Concept 3 Around the Block: aerial photo, draw-your-area list builder with live count and price. Concept 4 Signed, You: type a name, the letter and envelope on the table change. Concept 5 The Yellow Room: three plinths, pick what to mail.
- New render kit `tools/concepts/lib.js`: averages 64 to 96 samples with a moving key light, moving lens, and sub-pixel shift. This gives area-light shadows, focus blur, and clean edges from plain three.js.
- A real plant model and window bars placed off camera cast true leaf and window shadows. This was the largest gain in realism (concept 4).
- HTML on top of the render uses `mix-blend-mode: multiply`, so scene shadows fall across the type.
- Prices match `src/content/site.ts` (1,284 × $0.12 = $154.08; 1,284 × $0.94 = $1,206.96).

**What did NOT work:**
- Bash heredocs that contain backticks or `$(` failed in the Bash tool ("unexpected EOF"). Write files with the Write tool and patch with a Python script file.
- Headless Edge writes the screenshot after the launcher returns. `shot.sh` now deletes the old PNG and waits for the new one; before that, I viewed a stale image twice.
- ForgeGUI image generation is a game-asset tool and is not usable for photoreal plates.
- The first concept-5 idea used the CG mailbox; dropped because film-shots.js records that the mailbox did not reach photoreal quality.
