**Synopsis:** Owner feedback: #2 needed far more realism, #3 was bland, and no design may focus on real estate (YLS serves all industries); #5 Press Run was praised. Rebuilt #2 Special Delivery as a cinematic photoreal shot, replaced #3 with The Mailroom (a vintage sorting wall of audience slots for Build a List), and removed real-estate copy from #1, #4 and #5.

**What worked:** Evidence: `manual:` every image rendered headless and checked by eye. Realism came from three.js addons via the import map (`three/addons/` on jsDelivr r170): Sky, RoomEnvironment PMREM, EffectComposer with BokehPass, UnrealBloomPass and OutputPass, plus paper detail (stamps with punched perforations, postmarks, IMb-style barcodes, handwritten or typed addresses), bent envelope geometry, motion-blur ghosts and CSS grain. - `R` is a built-in PowerShell alias (Invoke-History), so a helper function named R silently never ran. Use a longer name (Rep).
- Large ghost offsets for motion blur look like glass panes; keep offsets under ~1 unit.

### [14:47] Round 3 concepts: #3 mail-piece POV film, #2 studio rebuild, #4 photoreal desk, #1 highlight removed   (branch: develop · commits: none)

**Synopsis:** Owner feedback: #2 messy and unrealistic, with terrible streaks; #3 Mailroom "not bad" but he prefers a background video of mail falling from the sky into suburban mailboxes from a mail piece's point of view; #4 still bland; #1 should lose the text highlight. Built #3 First Class (hero frame plus a 4-shot storyboard), restaged #2 as a clean studio product shot (floating mail and a phone with the delivery alert), rebuilt #4 as a photoreal designer's desk, and removed the highlight in #1.

**What worked:** Evidence: `manual:` every image rendered headless and checked by eye. A reusable scene module (`suburb.js`: houses with facade and shingle textures, mowed-stripe lawns, foundation shrubs, cars, curbside mailboxes with door and flag handles, Sky, GTAO). Leaf-card trees (about 300 alpha-tested cluster cards per tree, merged limb geometry) look far more real than displaced-blob crowns. Facade materials memoized by color, size and stories keep texture memory bounded across 130+ houses. Storyboard: one renderer and composer per shot, copied into 2D canvases; fog density set per shot.

**What did NOT work:**
- Mail pieces placed in camera space with large y offsets land at the top edge or behind the headline. Keep y/d under about 0.25, and check against the copy column.
- From altitude, a ground plane under 2 km shows its edge, and the default fog density turns the frame brown. Use a 9 km ground and per-shot fog.
- A camera inside a solid mailbox sees through back-face-culled walls. Build a BackSide interior and hide the outer meshes for that shot.
- `Object3D.lookAt` takes WORLD coordinates even for a child camera. Convert with `parent.localToWorld`.
- Procedural three.js still reads as high-end game CG, not film. The final background video likely needs a produced render or AI video.

**Artifacts:** docs/temp/redesign-concepts/ (01, 02, 03-first-class, 03-storyboard, 04, 05; source/suburb.js). 03-mailroom moved to rejected/. Memory: feedback_redesign_realism updated.

**Next / open:** Owner review. Decide how to produce the real #3 background video. Fix the Design System README "real-estate investors" line. Then phase 1 scaffold.

### [16:16] Built all five redesign directions in yls-redesign, with the First Class film   (branch: none, new untracked repo yls-redesign · commits: none)

**Synopsis:** Owner said "build them all", ultra-photoreal, videos especially. Built the review gallery (ported from ToddSpeciale4) and all five designs × five pages (home, templates, build-a-list, list-manager, pricing) in the sibling project yls-redesign. Press Run and First Class were built here; Personally Yours, Special Delivery and Cutting Mat were built by three parallel forks on the shared engine. First Class is a 9.9 s background film made from real Pexels footage plus three.js companion envelopes.

**What worked:** Evidence: `npx tsc --noEmit` clean, `npx eslint src` clean, `npm run build` succeeded (31 routes, all design pages static), `manual:` headless Edge GPU screenshots of every page plus browser-pane checks (no sideways scroll at 375 px; only expected /api/feedback 503s because DATABASE_URL is unset).
- Shared engine: plain three.js via `ThreeStage` plus `assets.ts` (HDRLoader env, Poly Haven PBR, GLTF, GTAO/DoF/bloom post chain). Photoreal look came from HDRI env at low intensity, a strong key light pool, DoF and bloom thresholds above paper white.
- Film: real footage for every shot, sped up with `tmix` frame blending for motion blur, reversed drone clips to fake descent, and companion envelopes rendered offline as RGBA frames with 8-sample shutter accumulation, then composited in ffmpeg with one grade and grain.
- Parallel forks with strict folder ownership did not collide.

**What did NOT work:**
- A procedural three.js mailbox finale (flat aerial plate as ground, then a product-shot version) still read as CG after several passes. Dropped it: the film ends on real footage and the site shows a live "Delivered" pin over the last frame.
- Unlayered design CSS beats Tailwind v4 utilities (for example, `hidden` lost to `.pr-btn{display}`). Wrap design CSS in `@layer components`.
- `fontFamily()` probed on `<body>`, outside the design root where the next/font variables live, so canvas text fell back to a default font. Now it probes inside `<main>`.
- An absolute container inside a component whose root is hard-coded `relative` collapsed to 0 height. Let the caller pass the positioning.
- PowerShell variables are case-insensitive: `$f` overwrote `$F`.
